Expand description

Converts standard Rust range types with byte-like bounds into borrowed byte bounds. バイト列として参照できる境界を持つ標準 Rust range 型を、借用バイト境界へ変換します。

Required Methods§

Source

fn start_bound_bytes(&self) -> Bound<&[u8]>

Returns the start bound as borrowed bytes. 開始境界を借用バイト列として返します。

Source

fn end_bound_bytes(&self) -> Bound<&[u8]>

Returns the end bound as borrowed bytes. 終了境界を借用バイト列として返します。
